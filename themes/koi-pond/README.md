# koi-pond

A theme for the Claude desktop and mobile apps: a painted pond seen from above, drawn in small cells behind the chat.

- Nine koi swim looping routes, weave and beat their tails.
- Now and then a koi comes up to the surface, and the cells of the grid lift in a ripple where it broke the water.
- Lily pads, mossy stones and reeds sit over the water; petals blow across; fireflies come out in dark mode.
- Works in dark and light mode, and pauses when the system asks for reduced motion.

## Install

```
/plugin install koi-pond --marketplace lmlong-huynh/claude-theme-mods
```

Restart the app afterwards. The terminal and editors draw no themes.
