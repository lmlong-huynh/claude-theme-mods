# koi-dark

A theme for the Claude desktop and mobile apps: pixel koi swimming on plain black behind the chat.

- Nine koi swim looping routes, weave and beat their tails.
- Now and then a koi brightens, and the cells of the grid lift in a grey ripple where its head was.
- No water, no plants, nothing else. The app's own surfaces go near-black with an orange accent.
- Made for dark mode only. Pauses when the system asks for reduced motion.

## Install

```
/plugin install koi-dark --marketplace lmlong-huynh/claude-theme-mods
```

Restart the app afterwards. Turn off any other theme from this repo first: each sets the whole look.
